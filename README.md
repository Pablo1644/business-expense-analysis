# Business Expense Analysis (Excel)

This project presents a business expense analysis created in Microsoft Excel.
It was developed as the **final project for the course about pivots in Excel**.

## Project Overview

The analysis focuses on exploring company expenses and transaction data using Excel tools. The dataset was validated and analyzed across several dimensions such as time, category, city, and brand.

## Key Analyses

* Data validation and consistency checks
* Monthly expense analysis for selected years
* Year-over-year (YoY) comparison
* Transaction count analysis, including transactions by city
* Brand and category expense analysis
* Comparison of weekday vs weekend transactions
* Average expense by category
* Forecast of future expenses based on historical trends

## Tools Used

* Microsoft Excel
* Pivot Tables
* Data validation functions
* Sorting and conditional formatting
* Trend analysis and forecasting
